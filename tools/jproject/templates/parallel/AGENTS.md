# Parallel folder: {{name}}

This folder develops something in parallel for the project container at:

    {{origin}}

Rules:
- Read the origin container only to read. Never write, move or delete anything there.
- Write only inside this folder.
- Put only the deliverable (classes, libraries, assets) in `out/`.
- Drafts, logs and tests go in `_work/`.
- When you finish, fill in `HANDOFF.md`: what you did, what you read from the origin, dependencies, how to integrate.
- `out/` and `HANDOFF.md` will be moved to the origin's intake folder (`HANDOFF.md` becomes `INTAKE.md`); everything else is discarded.
- Everything you develop is in English.
