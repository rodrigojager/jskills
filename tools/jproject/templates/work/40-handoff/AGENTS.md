# 40-handoff

## Purpose
State to resume a workstream later or hand it over to another agent.

## What goes here
- One `<workstream>.md` per workstream (create with `jproject new handoff <workstream>`).

## What does NOT go here
- A history of handoffs (each file is overwritten).
- Copies of content: reference files by path.

## Conventions
- Sections: goal, current state, next steps, relevant files (paths only), open decisions, suggested skills.
- Overwrite the file at every handoff. Never write handoffs to system temp folders.

## When to delete
- When the workstream ends.
