# 50-tools

## Purpose
Tools created by agents for this project (VPS deploy, batch edits, converters).

## What goes here
- Scripts and small tools, each with a header comment saying what it does and how to run it.

## What does NOT go here
- Scripts the product needs to build or deploy (the product's `scripts/`).

## Conventions
- `<tool>.<ext>`, one file per tool when possible. Edit in place; no copies.
- A tool moves to the user's global tools folder only if the user asks. Agents may offer when a tool is generic.

## When to delete
- When the user decides.
