# Workspace map: {{project}}

This is the map of everything in this container. Sections between `jproject:auto` markers are regenerated by `jproject map`; edit everything else by hand.

## 1. Container
| Item | Purpose | Rule |
|---|---|---|
| `AGENTS.md` / `CLAUDE.md` | entry rules for every agent | `CLAUDE.md` only imports `AGENTS.md`; edit `AGENTS.md` |
| `{{product_dir}}/` | the only git repository | only what the product needs to build, run, test and ship |
| `{{secrets_dir}}/` | real `.env`, keys, certificates | outside git; may be read, values are never copied anywhere |
| `{{work_dir}}/` | everything AI-generated | not versioned; route by the table below |
| `.agents/skills/` | project skills (canonical) | one folder per skill with `SKILL.md` |
| `.claude/skills/` | junction to `.agents/skills/` | same physical folder; do not edit separately |
| `.claude/settings.json` | Claude Code project settings | permissions, hooks |
| `.zvec-grep/` | search index (optional, if created) | managed by zvec-grep; never edit |

## 2. Work folders
| Folder | Purpose | What goes in | Naming | Lifecycle | When to delete |
|---|---|---|---|---|---|
| `00-tmp/` | scratch output | logs, temp files, dumps, analysis output, test builds | free | ephemeral | any time, without looking |
| `10-docs/` | documentation drafts | doc drafts, `BACKLOG.md`, `GLOSSARY.md`, `adr/NNNN-title.md`, `_render/` | one canonical file per topic | review | preserve backlog, glossary and ADRs; other drafts when the user takes or drops them |
| `20-design/` | visual reference | `mocks-img/`, `mock-html/`, `previews/` | canonical name + `_variants/<artifact>/` | review | variants: on consolidation; old previews: when a new one is made |
| `25-source-assets/` | heavy source files | `.blend`, `.psd`, `.spine`, `.kra`... | as the tool needs | review | when the user decides |
| `30-plan/` | live planning | `PLAN.md`, `PROGRESS.md`, `DIVERGENCES.md`, jtasks data | fixed names | live | before a different plan: carry pending work to BACKLOG.md, then run `jproject plan reset` |
| `40-handoff/` | resume or hand over a workstream | `<workstream>.md` | one file per workstream, overwritten | live | when the workstream ends |
| `50-tools/` | tools created by agents | scripts with a header saying what they do | `<tool>.<ext>` | reusable | when the user decides |
| `60-intake/` | accepted material from outside, to integrate | `<name>/INTAKE.md` + files | one folder per intake | transient | as soon as it is integrated |
| `70-proposals/` | generated here, awaiting a yes/no | `<name>/PROPOSAL.md` + files | one folder per proposal | transient | integrated or rejected: deleted without a trace |
| `80-ideas/` | future ideas, text only | `IDEAS.md` | one section per idea | review | a promoted idea leaves the file |

## 3. Routing
| I am about to produce... | It goes to |
|---|---|
| a log, dump, analysis output | `{{work_dir}}/00-tmp/` |
| unresolved work carried across plans | `{{work_dir}}/10-docs/BACKLOG.md` |
| a doc draft / ADR draft / glossary term | `{{work_dir}}/10-docs/` |
| HTML rendered from Markdown | `{{work_dir}}/10-docs/_render/` |
| a mock image | `{{work_dir}}/20-design/mocks-img/` |
| an HTML mock | `{{work_dir}}/20-design/mock-html/` |
| a preview/screenshot | `{{work_dir}}/20-design/previews/` |
| a heavy source asset (.blend, .psd...) | `{{work_dir}}/25-source-assets/` |
| a plan / progress / divergence update | `{{work_dir}}/30-plan/` |
| a handoff | `{{work_dir}}/40-handoff/<workstream>.md` |
| a helper script/tool | `{{work_dir}}/50-tools/` |
| material brought from outside | `{{work_dir}}/60-intake/<name>/` |
| something awaiting a yes/no | `{{work_dir}}/70-proposals/<name>/` |
| a future idea | `{{work_dir}}/80-ideas/IDEAS.md` |
| code, final assets, tests, build/deploy config | `{{product_dir}}/` |
| a secret | `{{secrets_dir}}/` |
