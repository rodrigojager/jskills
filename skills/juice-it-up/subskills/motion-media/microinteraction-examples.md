# Animated microinteraction examples

Look up the event in the product, then choose a pattern that makes its result clearer or gives an unusual moment some character. Each row links to working example source or the upstream implementation. The behavior and fallback columns describe how to adapt the example in the target product. The catalog is for proposing and mocking sequences. Each reference is selectable in the Lab to seed a suggestion. The example's element and event are starting points. Choose the cue, target and product trigger separately.

## Acknowledge an action

| Pattern | Trigger and visible sequence | When to use and what to preserve | GitHub example |
| --- | --- | --- | --- |
| Local reaction burst | A favorite or reaction turns on. Send a few short-lived particles out from its icon, then leave the selected icon in place. | Use an occasional reaction with a clear on/off state. On deselection, rapid taps or reduced motion, update the icon and count without particles. Reflect failures if the action syncs to a server. | [Risograph like button, HTML/CSS/JS and WAAPI](https://github.com/arslanagayev/like-button-animation/blob/main/script.js) |
| Milestone accent | A first successful publish, setup or other meaningful completion triggers a brief accent anchored to the completion control or mark. Leave the real completion state visible. | Tie it to a confirmed milestone and suppress repetition within the flow. Remove particles in reduced motion. Reuse an existing particle engine if present, or start with a tiny decorative DOM/SVG layer. | [Canvas Confetti, configurable origin and reduced motion](https://github.com/catdad/canvas-confetti#options) |
| Copy → check → copy | Once the clipboard write succeeds, swap the copy glyph for a check in the same slot, then reset the icon while keeping the control usable. | Useful for invite links and snippets. Keep an accessible name and announce the result. If the write fails, keep Copy available and expose the failure. For reduced motion, swap instantly. | [Animate UI Copy Button](https://github.com/imskyleen/animate-ui/blob/main/apps/v1/apps/www/components/buttons/copy.tsx) |
| Draw a completion mark | On a committed check or completed step, reveal the stroke of an inline SVG checkmark in place. | Useful when a quiet confirmation mark carries the feedback. Keep semantic checked/completed state immediate. Show the complete stroke immediately under reduced motion. | [SVG Animation Lab: checkmark draw-on](https://github.com/AleBrito124356/svg-animation-lab/blob/main/icons.html) |

## Make controls legible

| Pattern | Trigger and visible sequence | When to use and what to preserve | GitHub example |
| --- | --- | --- | --- |
| Hold fill with early release | An intentional hold advances a fill. Early release resets it. A completed hold triggers the chosen action or its confirmation. | Reserve for infrequent actions that benefit from added intent. Offer ordinary keyboard- and touch-accessible confirmation and handle cancellation away from the control. Under reduced motion, use discrete progress or immediate confirmation. The hold interval is interaction time. | [Microinteractions: hold to confirm](https://github.com/juandinella/microinteractions.dev/blob/main/src/components/HoldToConfirmButton.astro) |
| Play/pause icon handoff | When media actually starts or stops, the icon's layers exchange inside their existing bounds. They settle into the shape for the next available action. | Useful on infrequent playback changes. Keep the accessible label synchronized with the action. Interrupt the in-flight transition on reversal and swap instantly under reduced motion. | [SVG Animation Lab: play/pause](https://github.com/AleBrito124356/svg-animation-lab/blob/main/icons.html) |
| Directional chevron extension | Hover or focus extends an existing chevron into an arrow pointing toward the next or previous destination. The glyph returns on exit. | Use when direction already matters, such as an occasional step change. Keep the label and focus indication stable. On touch and with reduced motion, use a stable directional icon. | [Microinteractions: chevron morph](https://github.com/juandinella/microinteractions.dev/blob/main/src/components/ChevronMorphButtons.astro) |

## Preserve spatial context

| Pattern | Trigger and visible sequence | When to use and what to preserve | GitHub example |
| --- | --- | --- | --- |
| Card → detail → card | Opening a card carries a shared visual into the detail surface. Closing it returns to the visible source when possible. | Use for occasional object inspection. A reduced-motion version opens the same detail directly. Keep focus transfer, dismissal and focus return, including a fallback when the source card is gone. | [Motion Primitives: shared layout dialog](https://github.com/ibelick/motion-primitives/blob/main/components/core/morphing-dialog.tsx) |
| Results viewport settles | Filtering changes the measured height of a bounded results panel while the input keeps its position. | Use when the change is distracting and the panel can resize without shifting content around it. Keep filtering and selection immediate, constrain scroll, and disable the transition for rapid typing if it lags. For reduced motion, update height immediately. | [cmdk: height transition in the Vercel demo](https://github.com/dip/cmdk/blob/main/website/styles/cmdk/vercel.scss) |
| Sheet snaps or returns | A sheet follows a finger. On release it settles at the chosen stop, returns, or dismisses when allowed. | Use with a content-led reason for each stop. Keep ordinary expand/close controls and scroll behavior. Under reduced motion, place the sheet at the final stop immediately after release. | [Vaul: snap-point implementation](https://github.com/emilkowalski/vaul/blob/main/src/use-snap-points.ts) |

## Communicate work and changes in data

| Pattern | Trigger and visible sequence | When to use and what to preserve | GitHub example |
| --- | --- | --- | --- |
| Pending → result in one toast | A real async operation creates a pending toast. The same toast exchanges its pending indicator for a success or error icon once the outcome is known. | Useful for background actions such as exports. Keep the message actionable on failure, and avoid adding a toast when the control already gives enough feedback. Use static icons and text under reduced motion. | [Sonner: promise state](https://github.com/emilkowalski/sonner/blob/main/src/state.ts) and [loading-to-result icon handoff](https://github.com/emilkowalski/sonner/blob/main/src/index.tsx) |
| Progress inside the action | Starting a transfer adds a progress fill in the action control. Real measurements update it until success, failure or cancellation restores the appropriate next action. | Use determinate fill only when measurement is available. Keep a readable label or accessible progress value, distinguish retry from success and update the fill discretely under reduced motion. | [Codrops ProgressButtonStyles](https://github.com/codrops/ProgressButtonStyles/blob/master/js/progressButton.js) |
| Roll changed digits | A selected quantity or occasional metric update rolls its changing digits in the direction of the change, with a stable unit. | Use when the direction carries meaning. Keep the final value readable and available to assistive technology immediately. Use static updates for high-frequency data and under reduced motion. | [Number Flow: digit animation and trend](https://github.com/barvian/number-flow/blob/main/packages/number-flow/src/lite.ts) |

| --- | --- | --- | --- |

| Open from the anchor | Follow the actual attachment point after collision handling. | Widen and fade in | Animate an independent indicator. | Directional nudge | Move an existing directional glyph or compact control toward a meaningful destination, then return. | Turn to disclose | Rotate just the state icon into its new resting pose. | Reveal from an edge | Uncover the content from its real point of entry without animating layout dimensions. Leave the element's own shape intact. The Lab adapts these motion principles with the browser's Web Animations API. The contextual thumbnails play the same built-in motion as the canvas. A complete product interaction may need state, a trigger or more than one element.

## Turn a match into a suggestion

1. Read the matching example, then describe the target's event, before state, temporary cue, persistent state and the reason to add it. Suggest at most two treatments for the same event, each with a distinct purpose or intensity. Use the product's own iconography, tokens and normal event handlers.
2. Offer a preset and a meaningful variation. For particles, choose shape, direction, spread, count, color and the visual origin. The cue can anchor to a button, icon, card or status region and follow a click, a rare hover, a completion or a failure. Match the tone to the meaning. A failure might use a few muted falling rings beside persistent recovery text. Use the variation request for options beyond the built-in preview.
   For example, a confirmed upload in an editorial workspace could seat a document tab into the existing folder icon. A delivery confirmation in a logistics dashboard could complete a short route line at the destination marker. Both acknowledge a completed action using a shape or movement the product already makes meaningful.
3. Choose the simplest workable technique in the target stack. Use a built-in [Lab recipe](../lab/SUBSKILL.md#motion-library-in-the-lab) for a matching one-shot cue on a verified element. Build an isolated V0 and alternative preview for sequences that depend on async outcomes, SVG layers, multiple elements, geometry or gesture state. Include the actual trigger and interruption or failure path in the mock. An animation replay alone cannot validate those paths.
4. Check first use, fast repetition, cancellation and reduced motion. Preserve the real semantic state, keyboard and touch paths, focus and layout. If the source example has a simulated timer, illustrative dimensions or a different motion preference, tune it to the target data, behavior and frequency.

The Microinteractions studies are a good starting point for vanilla implementations and React examples. SVG Animation Lab and the risograph button show expressive effects in plain web code. Sonner, Motion Primitives and cmdk provide React implementation references for real component state. Vaul is marked unmaintained upstream. The Codrops demo uses simulated progress. This catalog uses the linked projects as design and implementation references. Check the license of any code or asset before reusing it.
